The bundled Until Loop runtime has a second unchanged-content gate and measures a directory outside Git.
- `required_trivial_reviews: 3` is for code reviews (ShipLoop's implement-step and last carry-forward reviews). A first pass that is trivial, satisfied and leaves the content as it started still ends the review; once any pass has changed the content, two consecutive trivial, satisfied passes that each leave it unchanged are needed. A pass that changed the content never ends the loop, however it is labelled. The runtime reads the pair from the latest report and the measured fact, so a gate-3 run keeps the state shape gate 2 has and its packets report the same `progress` keys with `required_trivial_reviews: 3`. Gate 2 is unchanged (one such pass). Values above 3 are refused. The published until-loop plugin reads 3 as three trivial reviews, so a gate-3 contract is for this bundled runtime only (recorded in `PROVENANCE.json`).
- A workspace that is not a Git worktree (an explicit in-place run) is measured through a throwaway bare repository in a temporary directory, with the same rule as a worktree: every file, the `.gitignore` files in the directory honoured, the runtime's own files left out, and nothing written into the workspace. `start` no longer refuses such a workspace; it refuses only when Git cannot snapshot the directory or a `candidate_paths` file is unreadable.
