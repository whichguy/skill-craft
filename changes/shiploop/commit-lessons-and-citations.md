Improve commits made through `improve-commit` now carry what the iteration learned: the message needs a `Key learnings:` line (or `## Key learnings`, or the label alone; `Key learnings: none` is the honest answer when nothing was learned), and a review that changed no file still makes no commit and is never asked for lessons. `Learned-from: <commit id> <what it contributed>` lines are optional and checked: Git resolves each ID to a commit reachable from HEAD, and a unique prefix is written into the commit as the full ID. `improve-commit --remote-change` records a change to a remote system that left no file change as a commit with no files (the message needs a `Remote change:` section). Every refusal puts the fix and the exact next command on its first line, and the Improve import refusal for uncommitted edits now names `improve-commit` and the `--no-commit` exit instead of telling the child to run `git commit`. Commits ShipLoop makes now use `--cleanup=whitespace`, so a `## ` heading in a message survives a `commit.cleanup=strip` setting. The commit rules live in `parent-return.md`, which the frozen Improve contract already names.
