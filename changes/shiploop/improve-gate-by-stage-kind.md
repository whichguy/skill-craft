ShipLoop starts each Improve review at the gate its stage kind names. The reviews after the seven document stages (spec, test-strategy, plan, step-plan, test-spec, system-test-author, release-plan) keep the one-pass rule: a trivial, satisfied pass that leaves the content unchanged ends the review. The review after each accepted implement step and the one after the last carry-forward, which review code, run at `required_trivial_reviews: 3`: a first pass that leaves the content as it started still ends the review, and once a pass has changed the content it takes two such passes in a row. The runtime measures this; the label is never enough and there is no cap or timer. The review's exit and repeat conditions and its handoff say which rule applies, and the import accepts a completed review from either gate. The scope is a proposal awaiting the owner's SPEC S-10 text. An in-place run outside Git can now start its Improve review (the runtime measures a directory that is not a Git worktree).
