2. Expected versus seen

What we expect of every run, and what the findings tagged to each expectation say. Changing an expectation is an option in step 3, not an edit here.

The contract we must not break

One sentence in, then investigation, planning and an iteration loop. The skill never decides the flow. The script does, and the skill obeys what it returns.

Skill

Calls the script. Does exactly the step the packet names. Calls back with its result.

Script

Reads and writes state. Decides the next stage, writes every contract, refuses anything inconsistent.

State

The only source of truth. It tells the script what the very next prompt is.

request → investigate → plan → [ skill calls script → script updates state → state names next prompt → skill obeys ] → repeat → release
