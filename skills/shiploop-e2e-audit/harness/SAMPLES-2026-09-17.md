## Findings and apparatus corrections

1. **Grok did load the intended skill.** Native tool events show reading the
   selected `SKILL.md` and executing the package's actual bundled CLI. This is
   execution evidence beyond `grok inspect` discovery alone.
2. **The login shell rebuilt PATH.** In the preliminary attempt, `git` selected
   the Xcode installation with an unresolved license rather than the Git
   selected by the runner. A child-only `DEVELOPER_DIR` override fixes this;
   it does not change the system selection or accept a license.
3. **Both initial xhigh requests hit the empty-tree bootstrap defect.** After
   an empty Git commit, `workspace start` reported
   `cannot capture working tree with git add -u`. Grok added and committed a
   README, then successfully started another workspace. Checkers also first
   hit `workspace root parent does not exist`. ShipLoop intentionally allows
   Git bootstrap before the DAG, but these extra failures/workarounds are
   concrete targets for a subsequent ShipLoop improvement and regression case.
4. **Workspace capture was too narrow.** Tic-tac-toe chose the campaign-level
   `.shiploop-runs`, one level above the original default. Defaults now include
   both parent and grandparent `.shiploop-runs`; other locations remain explicit
   `--artifact-root` inputs. Missing state cannot silently pass.
5. **The sanitizer delayed the final callback.** An offline idle-stream regression
   exposed a held safe tail. Complete safe NDJSON lines now reach the observer
   promptly, while split/multiline credential prefixes remain protected.
6. **Multiline shell commands needed proper segmentation.** A leading `mkdir`
   followed by the CLI on another physical line was merged into one command
   during analysis. The adapter now preserves unquoted command boundaries,
   quoted multiline values, comments, and line continuations. Narrow standalone
   quoted Python heredocs are supported; other heredoc shapes stay unverified.
   Tests cover real observed command shapes.
7. **Partial success is distinct.** It requires durable prefix acceptance,
   correlated callbacks, the requested stop signal, zero later accepted
   actions, stable selected skill, and complete capture. Timeouts, overruns,
   and missing evidence are not passes. Full game verification is still separate.
