# Environment

The repository is plain HTML, CSS, and JavaScript. Node's built-in node:test runs with node --test; no package installation is needed. The stage host provides a local Playwright module and Chrome executable through PLAYWRIGHT_NODE_PATH and BROWSER_EXECUTABLE_PATH. A capability-only probe found those routes; it did not inspect this product. Use a rendered browser check before claiming a visual result. No remote browser or external service is part of this task.
