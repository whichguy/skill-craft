# Architecture and decisions

## Decisions

### AD-1 — Retro page direction

#### Retro system and colors
The explicit retro arcade/pixel direction takes precedence over the light default. Apply the whole-page treatment, including the board, controls and surrounding surfaces. Use a dark field `#25202a`, amber `#efb849`, cream `#fff1c9`, `2px` square borders and `0.875rem` monospace type.
