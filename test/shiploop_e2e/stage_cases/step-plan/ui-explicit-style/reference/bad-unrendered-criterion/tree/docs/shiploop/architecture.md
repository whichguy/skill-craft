# Architecture and decisions

## Decisions

### AD-1 — Selected-square summary strip

#### Explicit direction and scope
The user's explicit retro arcade/pixel request takes precedence over the light profile. The treatment is confined to the selected-square summary strip below the board. Keep the board and rest of the page unchanged.

#### Strip tokens and placement
Use a charcoal panel `#25202a`, amber `#efb849`, cream text `#fff1c9`, `2px` frame, `0.75rem` spacing and `0.875rem` monospace type. Place below the board and preserve selected/empty states.
