# Architecture and decisions

## Decisions

### AD-1 — Selected-square summary strip

#### Explicit direction and scope
The user's explicit retro arcade/pixel direction takes precedence for the selected-square summary strip. Confine it to that strip; the board and rest of the page remain unchanged.

#### Strip tokens and placement
Use a charcoal panel `#25202a`, amber `#efb849`, cream text `#fff1c9`, a square `2px` frame and `0.75rem` spacing. Use `0.875rem` monospace type and show selected and empty states.
