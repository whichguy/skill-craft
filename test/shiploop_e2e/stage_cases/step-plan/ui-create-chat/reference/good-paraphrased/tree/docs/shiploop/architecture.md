# Architecture and decisions

## Decisions

### AD-4 — Local chat interface

Status: accepted first direction for the local chat.

#### Palette and typography

The light-first default uses --page #f7f4ee, --panel #ffffff, --ink #263340, --accent #b94f38 and --focus #8d3326. Use font-family: "Inter", Arial, sans-serif.

#### Conversation layout

The conversation layout stays readable at a content maximum of 70rem. Keep conversation selection, messages and the composer in a clear local flow.

#### Dark treatment

The dark option uses --page #202833, --panel #303946, --ink #f4f1eb and --focus #f3bd68. Retain an obvious active-conversation accent in both themes.
