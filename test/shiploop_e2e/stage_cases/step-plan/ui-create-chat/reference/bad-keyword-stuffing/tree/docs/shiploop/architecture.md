# Architecture and decisions

## Decisions

### AD-1 — Local chat interface
Accepted direction. Use system-ui; light default and dark option.

#### Design system and tokens
Do not use --page #f5f2eb, --panel #ffffff, --ink #24313d, --muted #5a6874, --accent #4f66bf, --focus #344e9c. Avoid 72rem and 1rem.

#### Components and composition
Avoid a 72rem content layout.

#### Theme
Light default; do not use #18222e.
