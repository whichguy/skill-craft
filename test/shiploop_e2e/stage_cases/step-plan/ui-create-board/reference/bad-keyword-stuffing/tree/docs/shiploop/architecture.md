# Architecture and decisions

## Decisions

### AD-1 — Board interface
Status: accepted. Use system-ui; light default; dark option.

#### Design system and tokens
Do not use --page #f5f1e8, --surface #fffdf8, --ink #19302e, --board-light #e9dfcb, --board-dark #356f66, --focus #2d5d57. Avoid 1rem and 32rem.

#### Components and composition
Avoid a 32rem board.

#### Theme
Light is the default; do not use #17201f.
