ShipLoop 0.14.0 now resolves the selected card's declared runtime, lets each
child own its temporary callback state, and imports a validated raw terminal
packet after the child deletes that state. The packet retains scoped context,
parent identity, evidence and return routes for compaction recovery. ShipLoop
still owns only parent traversal; semantic review judgments remain with Improve.

Key learning: replacing a runtime binding alone was insufficient because the
old importer required durable v2 state/history. Terminal output must survive as
an import receipt. Another integration finding was that the final workspace
return precedes child import: excluded untracked child receipts must remain in
the private worktree, while staged, committed and historical runtime files must
still block return. Do not create another child journal or scheduler.

Validate real material/trivial/trivial callbacks, wrong or missing receipts,
legacy compatibility, relocated read-only packages, terminal cleanup, return
ordering, and actual 34-stage source/generated/observer composition. A fresh
agent given only a terminal packet successfully imported one parent result;
these protocol fixtures do not prove live product review quality.

Focused checks and core suite passed; full regression groups and PR CI provide
