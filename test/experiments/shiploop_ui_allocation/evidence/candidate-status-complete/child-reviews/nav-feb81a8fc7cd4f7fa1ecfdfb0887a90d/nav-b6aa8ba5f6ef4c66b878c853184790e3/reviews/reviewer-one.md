# Independent review — cycle 1

Scope reviewed: the W1 step plan, controlled identity contract, request/boundary,
and copied Field Notes baseline. This was a fresh read-only review; it did not
inspect the preregistered oracle or edit the candidate.

Material findings:

1. Clearing a status snapshot on an account switch while retaining its previous
   revision makes a later equal-revision response a no-op, leaving the returning
   account empty indefinitely. The plan needed an explicit no-announcement
   rehydration exception for a cleared current account.
2. A blanket assertion of no POST conflicts with the preserved note-save POST.
   The negative test must scope itself to requests generated by the new observer.
3. The proposed status UI needed explicit loading, empty, retry-pending, error,
   and accessible retry/announcement behavior, rather than only a component
   list.

The review found no W1/W2 scope expansion and no false live-deployment claim.
