# Native planning pilot protocol

Frozen before observing baseline or candidate behavioral results, 2026-09-22.
The baseline is ShipLoop f14103d20e2219cd14f652f91dbc1725908464f2 from
baseline-source.json. Candidate identity will be captured before dispatch.

A: independently opened SQLite connections in worker processes must consume
coordinator-seeded state; provisional research/plan chooses ':memory:'.
B: no-overwrite publication is required; provisional test strategy treats a
successful Path.rename return as proof existing destination bytes are preserved.
C: sufficient current supplied same-target evidence is available; avoid an
unnecessary new probe. This supplied evidence is synthetic fixture input.
D: required target/probe is unavailable; retain unresolved status rather than
infer a valid negative or readiness.

Use identical substantive inputs, isolated workspaces, actual selected Improve
and Until callbacks for A/B, and the source-generated plan Improve prompt for
each version. Candidate adds only its delivered v4 guide/context. Native workers
cannot edit upstream accepted documents or call parent callbacks; parent collects
terminal workers and imports results through the actual version's CLI. Prior
unrelated stage setup may use explicitly synthetic receipts; this is a component
pilot, not generated-product or full lifecycle evidence. Never run an unavailable
v3 transition by manually editing state.

Grade correct plan consequences, preserved facts, honest evidence classification,
actual probe commands/results and identities, zero false readiness, zero scope
expansion, and supported parent disposition. A and B should expose the selected
mechanism's failure to meet the stated requirement. C should reuse sufficient
current evidence; D remains unresolved. Names/tool wording are not scored.

Record actual probe count, wall time, available model identity, callback status,
and token cost only if reported by the host (otherwise unavailable). Default
adoption requires two distinct consequential planning improvements over baseline,
at least one replicated in a fresh candidate trial, no lost correct baseline
finding or false readiness/unauthorized effects, and regression/recovery pass.
Acceptable overhead for a default switch: candidate total active elapsed no more
than twice baseline plus two minutes, with no additional gratuitous probe in C.
If no comparable active-time evidence exists, the default gate is unproven.

The opt-in capability can be delivered after deterministic transition and recovery
proof even if semantic trials tie; v3 remains default. Report limitations and do
not turn the pilot threshold into a claim of generalized benefit. Retain all
incomplete/cancelled attempts. A distinct independent grader reviews outputs after
both arms return without rerunning probes. If a candidate improvement merits
adoption, repeat it in a fresh native context before switching any default.

## Reproducing the apparatus

From the repository root, `python3 -B
test/experiments/shiploop_planning_experiments/probe.py A` runs the SQLite
comparison; replace `A` with `B` for rename behavior. Each invocation creates and
removes its own temporary directory, records platform/runtime identity, and
prints observations. Inspect command/exception outcomes before interpreting them:
an unavailable or failed apparatus is not a negative domain result.

These probes reproduce the local mechanisms. They do not reproduce native model
behavior, Until ownership, or parent reconciliation by themselves. The behavioral
pilot used independently authored scratch probes with the same discriminators.
Its findings and protocol evidence are in
[the results report](../../../docs/shiploop-planning-experiments-results-2026-09-21.md).
