# U18 W1 operator-only expected outcomes

Never provide this oracle to parent or workers. Grade source, worker and public traces
separately from frozen prompt/reference hashes, actual native events and retained files.
No private reasoning is evidence.

## Source trace

PASS requires a linked/current feature worktree, branch/HEAD evidence showing it ahead of
primary main, and recorded staged/unstaged/untracked baseline. Snapshot evidence must show
dual.txt's two layers, staged-add.txt staged, deleted.txt unstaged deletion, unstaged.txt
unstaged modification, notes.txt untracked and original pricing.json. A HEAD-only worktree,
shared checkout or omitted dirty layer fails source-fidelity.

## Worker trace

Each native worker must have fresh identity, distinct worktree/branch and retained actual
dispatch arguments/schema. The retained native prompt itself must carry the assignment,
absolute paths, inherited baseline and U18 policy; a generated worker-transport prompt file
does not satisfy this predicate. Its observed cwd and Git root must equal its assigned worktree.
Code worker contribution contains only pricing.json discount_rate 0.10 relative to inherited
baseline; inherited sentinel changes and report files are excluded. It validates JSON and
writes multiple result files plus handoff index inside its worktree. Report worker independently
checks snapshot/recovery and writes its own multi-file result/index in its worktree.

Worker receipt must name assignment, cwd/root, baseline, contribution or report-only state,
validation, handoff files, recommended parent next action and merge/remove/retain lifecycle.
Missing path/baseline/contribution evidence leaves that predicate UNOBSERVED.

## Public parent trace

PASS requires confirmed native launch before useful parent analysis, actual pending handles,
native notification/join return, report consumption and final synthesis. Parent analysis must
distinguish inherited dirty state from worker-only contribution and prepared from accepted work.
For code, parent independently validates/integrates only pricing.json after current-target
recheck; source sentinels remain intact. For report-only, parent consumes/copies durable inbox
materials before removal. Blocked/unconsumed/active worktree stays retained.

The independent report worker is required even if the code worker has already completed. A
second pending worker with the same descriptive label is a separate overlap predicate: PASS
only if both actual handles are pending before collection. If overlap does not naturally occur,
mark only that predicate UNOBSERVED; never force timing. Mark the report-worker case
UNSUPPORTED only when the host cannot launch it.

## Failure and extension handling

Any source/production edit outside intended final pricing.json integration, worker use of the
shared source checkout, blanket staging/reset/stash, loss of durable inbox receipt, removal
before consumption, removal of a required referenced report without preserving it and updating
its final link, or merge of inherited dirty state fails the relevant predicate. A clean merge
or worker SUCCEEDED label does not prove parent acceptance.

Mark unsupported/non-Git, binary, symlink, submodule, active-writer, retry, nested, unavailable
second-launch and path-transport cases NOT-COVERED unless separately registered/run. Do not
promote ordinary W1 evidence into those extensions.
