# Round 2: equal information and bounded reconciliation

Frozen before round-2 model trials, after inspecting all six round-1 answers.
No round-1 judge verdict was yet available when designing this follow-up.

## Observations motivating replanning

Both drag answers retained existing behavior using existing documentation/tests.
Both refresh answers replaced obsolete refresh assertions, without old-request
replay. The contract-aware retry answer identified a privacy conflict which the
code-first answer could not know. Both retry answers raised duplicate-delivery
questions and gated enabling retries; do not attribute this to the contract cue.
The data do not establish a need for a mandatory new feature document.

## Revised hypothesis

Relevant retained intent may help; a long new instruction may not. Compare the
original code-first instruction against a shorter reconciliation cue, now giving
both conditions **exactly the same product evidence**. Do not imply that a cue
can recover information that was never retained. No production edits follow
automatically from a win.

1. `equal-retry`: repeat the notification case with the approved diagnostics
   contract supplied to both. The existing retry oracle now applies with the
   contract present for both; no information-availability exemption.
2. `recovery`: held-out cold planning recovery. Preserve the same saved request
   and current planning assignment, recognize a partially written search path
   that violates explicit access rules, repair/propose necessary filter ordering,
   test unauthorized rows are never exposed, and do not infer passed tests or
   completed work from a draft result. Do not restart a run, replay the archived
   admin-export proposal, or weaken the approved access contract.

Each case gets two independent fresh sessions. A is the original cue, C is the
shorter cue. Judge uses randomized anonymous positions, seven standard dimensions
plus the frozen mandatory checks. Results remain a small same-host interpretation
pilot, not statistical proof of equivalence or real execution. We will not claim
the recovery case traversed actual ShipLoop state or performed tool calls.

The final decision should retain only the parts supported by the observations:
conditional preservation of otherwise-lost promises, existing canonical homes,
explicit intentional change, and honest unresolved differences. A tie with equal
information is evidence against claiming the new wording itself is necessary.
