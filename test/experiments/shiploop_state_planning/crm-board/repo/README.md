# Demo board

This is a local synthetic board. Account labels and principal IDs are fixtures,
not people, organizations, or CRM records. `access.py` is a modeled policy
snapshot, not a live IAM or CRM interface. A change to an assignment requires a
policy-owner decision; no repository edit grants a real account access.

Run the existing local verifier with:

```sh
python3 verify_board.py
```
