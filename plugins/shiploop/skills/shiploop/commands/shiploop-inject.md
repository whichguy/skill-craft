# Removed: /shiploop inject

ShipLoop 0.9 intentionally has no mid-flight inject-step command. A newly
discovered need is not a license to write part of the authoritative DAG or
receipt outside the current action.

Record the evidence and learning during the active step. At post-inner, answer
whether broader dependencies, preparation, or tests must change. A revise
result can replace the plan and DAG transactionally only for pending steps,
after validation; it cannot mutate completed or running work, silently change
the goal, or erase evidence.
