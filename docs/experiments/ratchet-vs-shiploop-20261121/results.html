Head-to-head · four cases · one run each

Ratchet or ShipLoop?

On small requests ShipLoop with one look and one fix matches Ratchet at under half the time; on the large stateful one Ratchet is still the better feature.

Three rounds: the first script measures on eight runs (below), a deeper judge that runs every product and checks it item by item, and clean ShipLoop runs followed by one look and one fix. Ratchet's side is one run a case throughout.

Each arm ran on its own in a new Git repository, on Codex gpt-6.2-sol at medium effort, from one checkout: ShipLoop 2.4.1 through the E2E harness, Ratchet through the pilot loop with its reworded specification text. Margins for “ahead” were registered before any run.

ShipLoopRatchet▏ Ratchet at its first build

A deeper judge: each product run and checked item by item

Every product was audited by running it against a list written without seeing any product: what the request states, and what it leaves unsaid that a customer would care about. Every disagreement and every reported defect was then tried on all three products of a case, and two judges of different model families read the audits. Ratchet's first build costs the same as ShipLoop's whole delivery.
