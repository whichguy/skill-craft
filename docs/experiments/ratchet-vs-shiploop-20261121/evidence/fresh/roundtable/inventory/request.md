Build a small local project-room app titled "Roundtable", served by server.js using Node.js with no npm dependencies. It listens on PORT (default 3000), and GET / serves the app. Give it a light, Gemini-like look and feel. Start with one room named Launch plan, seeded with a realistic conversation containing at least one message each from Maya and Theo (people) and Scribe (a clearly identified demonstration agent); the current user is Maya. A region named Conversation contains the messages as articles showing author, person/agent identity and time. Each message article is accessibly named Message from Maya, Message from Theo or Message from Scribe using its actual author. A textbox named Message and a Send button compose a message; Enter sends, Shift+Enter inserts a newline, whitespace-only text is ignored, and sending preserves multiline text and clears that draft. Sending a message containing @Scribe calls the local POST /api/agent endpoint with JSON {"text": the complete sent text}. The deterministic endpoint returns exactly {"text": "Demo reply: " followed by that text}, rejects whitespace-only text with HTTP 400, and uses no external service. While awaiting a reply, show a working state with role status. On a failed response, show an alert and a Retry Scribe button; retry the agent reply without duplicating the person message. The URL /?empty=1 starts an empty conversation with useful guidance, where sending still works; this fixture control is not a normal UI feature. Provide a visible Use dark appearance button that switches the appearance and becomes Use light appearance, which switches it back. Keep reading and composing usable at 320px and 390px narrow browser widths and a 1440px wide browser width without page-level horizontal scrolling. State can live in the current browser session. Cover the state rules in a module the app uses with node:test tests under test/ that run with node --test. This first delivery is one room and one local agent: no accounts, file sharing, canvases or external services.
