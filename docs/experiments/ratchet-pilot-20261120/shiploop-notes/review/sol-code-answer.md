## Admission, ledger and packet checks

| Path | What the build does |
|---|---|
| Fresh producer `check` | One note-file read and one gate before `_evaluate`. It records no on a normal note refusal. The dry run leaves acceptance untouched. Findings 1, 6 and 7 qualify the result. |
| Fresh producer `complete` | One note-file read and one gate before `loops.check_terminal` and the remaining gates. A successful callback can read again to render the **next** packet. Terminal handoff also reads in `_end_read`, in report generation and in done rendering. |
| Reuse of a check’s yes | Runs the current note gate before looking up and taking the yes. A fault at that gate replaces a matching reusable yes with no. The later handoff exception is in finding 4. |
| Parked producer replay | Zero note reads for that callback’s admission. The exact seed can replay with ordinary gates satisfied. A changed seed cannot take effect, although `check` can give it a false yes. Previously accepted producer replays also cannot add a history row. |
| Review `complete`, no `--final-result` | One import validation against the parked seed, zero note-file reads for admission. The child’s skill and receipt prerequisites are separate from the producer loop gate. A note that arrives during review waits for a producer. |
| Review `complete --final-result` | Same read count. I ran the validator with a dropped row, a changed valid row and an added row. It refuses the drop and addition and accepts the valid change. A changed non-`done` outcome leaves the seed rows out of the ledger. Canonicalization forbids any `notes` field on that outcome. |
| Paused or blocked producer | `resume` restores an active cursor and accepts no producer result. Pause keeps the action. A blocked result creates a fresh action at the same stage. The next producer submission takes the regular admission path. |
| Script-recorded stages and reconcile | Matching `validate-existing`, left-out `test` and left-out `document` owe no row. A synthetic document that parks for review also has an empty expected set at import. `improve-reconcile` records a non-`done` plan event, so it settles nothing. |
