### 4. The queue rule can require and forbid the same row — e

**Verified queue semantics.** At `plan`, supplied `work_items` replaces the full queue. Omission retains the existing queue, subject to the other gates. ### 5. A first-sentence refusal must work after CLI formatting, and the gate can stall — g, h
