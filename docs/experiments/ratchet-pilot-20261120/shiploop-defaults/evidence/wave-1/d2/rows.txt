1. R-1 How do operators enter the hours? Decided: One positive whole-hour variable per priority. Otherwise: A JSON setting updates all priorities as one value.
2. R-2 Does the exact deadline count as overdue? Decided: It counts once the clock is later than the deadline. Otherwise: Count the deadline instant itself as overdue.
3. R-3 How do existing files get prepared before enabling? Decided: Run one offline migration command, then enable the switch. Otherwise: Start a preparatory release that migrates its file during startup.
