On the remaining prompt and control-flow questions:

- **Leaving failing acceptance tests in place is consistent with the scheduler.** The tests session ends, the suite freezes, the parent gates, and failures go to fix. It does not need its own all-green Until Loop.
- **The dispute route is workable if treated as an incomplete inner loop.** It should explicitly say to write the dispute report, return blocked/unsatisfied through the callback, and let the parent invoke the referee. Claiming a satisfied inner-loop exit while its gate fails causes another iteration.
- **The conduct rule conflicts with the supplied runtime instructions.** “Nothing outside this folder is yours to read … or change” conflicts with reading sibling tools/contracts and invoking a runtime that writes sibling receipts. The specific commands imply exceptions, but a careful model has to infer them. Name those permitted paths explicitly.
- **Using the product during delta is compatible with prohibiting product edits.** Temporary probes and data should go under the permitted temporary directory. Ordinary persistent changes outside the two allowed files are reverted. Ignored runtime data can survive, and legitimate product use that writes tracked data may be reported as a role violation.
- **The ordinary frozen-pointer sequence is coherent.** Plan freezes the updated spec, tests freeze their suite, referee freezes a correction, and delta freezes the enlarged spec. The dangerous cases are accepting altered protected files into a new freeze, failed-stage acceptance, and importing a source run’s HEAD without a pinned suite identity.
- **The registered apparatus stops are present.** Stuck, max-fixes and max-cycles are explicit. However, a later failed final gate does not replace `stop: converged`, and `Run.run()` returns zero for all normal terminal stops; consumers must inspect the record.
- **Input copying is a merge, not exact replacement.** Stale destination files can survive `copytree(..., dirs_exist_ok=True)`. Inputs containing `.git` or Ratchet-owned paths are not rejected. Also, `--frozen-from` with `--build-from` is accepted, but repair-start control flow skips the given build entirely. Reject incompatible flags and reserved input paths.

The selftest’s successful guard cases remain useful evidence for ordinary final-state edits. They do not exercise these control-file changes, command-time mutations, failed-stage completion paths, grading interference or historical-reading gaps.
