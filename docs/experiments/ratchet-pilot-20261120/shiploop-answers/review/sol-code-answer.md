### Admission and compatibility

15. **The normal producer paths share the intended cutoff.** `dispatch()` reads once for `to_hold()`, `_evaluate()` or the matching-yes recheck, and `deliver()`. Delivery intersects that snapshot with packet-shown IDs. A hold-only note can therefore be applied without being delivered, and a delivered bound note can still be owed after blockage or reconcile. With a readable inbox, `standing()` picks the latest note per row, closes intake at the parked seed, and takes application from the projected accepted result.
