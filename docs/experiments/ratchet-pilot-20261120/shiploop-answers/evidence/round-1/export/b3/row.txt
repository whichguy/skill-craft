4. R-5 Does the new release add due times to the data file before DUE_TIMES is on? Decided: Yes: at the first start the file is rewritten with a due time on every ticket, with no visible change in answers; the operator then sets DUE_TIMES=on. Otherwise: Backfill only when DUE_TIMES is on; but then the file would not hold them when switched on, contradicting the request. Selector: 4@c1cbd38d.
