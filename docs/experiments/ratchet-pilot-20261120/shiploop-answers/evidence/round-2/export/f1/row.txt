3. R-5 When do existing tickets get their due times, given the file must hold them before DUE_TIMES is on? Decided: The first start of the new release on the production file fills every missing due and rewrites the file, even with DUE_TIMES off; operators then set DUE_TIMES=on. Otherwise: A separate one-off command that backfills the file, which operators would have to run before starting the new release. Selector: 3@97901003.
