## Discoveries

- The human CLI must distinguish an unassigned ticket from a ticket assigned to a name that equals the displayed marker. | Observable: List the same ticket with null ownership and with the one-character name `-`. | Why: The current CLI prints the same row in both cases.
- An assignee-filtered cursor holds a position in the live result set across ownership changes, including when the ticket that established the position stops matching. | Observable: Fetch a page, assign matching tickets on both sides of its last ID, clear that ID's owner, and follow the cursor. | Why: The following page includes the new match ahead of the position and leaves the earlier match behind it.
