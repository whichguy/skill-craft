# Acceptance tests, cycle 1

The manifest selects each of the 45 clauses and six use cases independently. The service and CLI are exercised in separate processes on free ports and with isolated files. The default-port case observes the requested port at Node’s socket boundary and binds an ephemeral port. The crash test interrupts a live save on filesystem activity. The relay replay case restores the saved pending checkpoint while retaining the emitted relay line, reproducing the durable state of a send that was never recorded. The legacy fixture was written by the service at the original revision, `5a31304`.

## Failing now

- **C-34** accepts a saved 65-letter assignee and starts serving the file. Numeric and empty-string values are refused.
- **C-40** renders a valid agent named `-` identically to an unassigned ticket. The normal listing and filter cases pass.
- **C-44** discovers assignment API tests under `test/`, but none exercises CLI assignee visibility.
- **C-45** returns `500 internal` on failed assignment, reassignment, and clear saves but exposes the changed owner, update time, and audit in running state. Failed assignment and reassignment also leave new notices. A later unrelated save persists those changes, and retrying after restart becomes a no-op.

## Discoveries

- If a service accepts equivalent spellings for an assignment, the ownership filter should recognize the same equivalence without choosing a spelling policy here | Observable: PUT `{"assignee":" Dana "}` and compare the results of `GET /tickets?assignee=%20Dana%20` and `GET /tickets?assignee=Dana` | Why: the build accepted the padded name and stored `Dana`, while only the unpadded filter found the ticket.

## Preserved behaviour

Assignment covers the dedicated PUT route, ticket representations, assignment audit and notices, ownership filters, and human-readable CLI listing. Create and edit retain their original input fields. Exact PUT success shape, agent spelling policy, inactive repeats, treatment of superseded notices, invalid or repeated assignee query values, and additional raw CLI columns follow the specification’s open points.
