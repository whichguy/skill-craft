## Discoveries

- Specify which endpoints interpret alternative spellings as the same agent when the requester resolves the identity question | Observable: Assign using a space-padded name, then query using the original spelling and the displayed spelling | Why: This build stores ` Dana ` as `Dana`, and the padded query returns no matches while the displayed spelling matches.
- State explicitly how simultaneous CLI status and priority options combine | Observable: List a file containing one ticket that matches both options and others that each match only one | Why: The baseline CLI used the shared disjunctive predicate, the build uses a conjunction, and C-40 describes the options without specifying their combination.
