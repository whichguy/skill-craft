Host binding (Codex). Start every sub-agent with spawn_agent (fork_turns "none", a short task_name) and make all the spawn_agent calls for the ready ids together in one response (parallel tool calls), not one per turn. Wait with wait_agent and a long timeout_ms (for example 120000), not short polls: it returns when an agent finishes, and then you run the ready call again. You hold one of the four concurrency slots, so at most three sub-agents run at once.
