- **(a) Grok Build** ([guide](https://github.com/xai-org/grok-build/blob/main/crates/codegen/xai-grok-pager/docs/user-guide/16-subagents.md), [launch 2026-05-25](https://x.ai/news/grok-build-cli), [workflows 2026-07-23](https://x.ai/news/workflows)). `spawn_subagent`: prompt, `run_in_background` (default true), `isolation` none|worktree, `resume_from`, types general-purpose/explore/plan/custom. Depth 1; `max_concurrent` (default 32, inferred) with `limit_behavior` queue|fail ([config](https://github.com/xai-org/grok-build/blob/main/crates/codegen/xai-grok-pager/docs/user-guide/26-config-reference.md)). - **(b) Kimi Agent Swarm** ([K2.5 report 2026-02-02](https://arxiv.org/abs/2602.02276), [blog](https://www.kimi.ai/blog/kimi-k2-5), [K2.6 blog](https://www.kimi.com/blog/kimi-k2-6), [help](https://www.kimi.com/en/help/agent/agent-swarm)). Max: 100 sub-agents/1,500 tool calls (K2.5 blog; paper states none); 300/4,000 from K2.6, still listed for K3 Swarm. Eval step caps: orchestrator 15-100, sub-agent 50-100. PARL: trainable orchestrator, frozen sub-agents; tools `create_subagent`/`assign_task`; reward λ1·r_parallel + λ2·r_finish + r_perf, λ annealed to 0 (counters serial collapse and spurious parallelism). Critical steps = Σt(S_main + max_i S_sub,i). Sub-agents keep bounded context; only task-relevant outputs return, not traces. Speedup: WideSearch time-to-target 3x-4.5x lower (abstract: up to 4.5x latency); blog adds 80% runtime cut (internal, no benchmark named). Accuracy: BrowseComp 60.6→78.4, WideSearch 72.7→79.0, in-house Swarm Bench 41.6→58.3. Stated caveats: that bench rewards parallel decomposition by design, synthetic training prompts, timing only on WideSearch, research preview/beta, several-times credit cost. [K3 report 2026-07-27](https://arxiv.org/abs/2607.24653): only Swarm Bench 76.3; no PARL detail found.

- **Kimi Code CLI** ([agents](https://www.kimi.com/code/docs/en/kimi-code-cli/customization/agents.html), [tools](https://www.kimi.com/code/docs/en/kimi-code-cli/reference/tools.html), [changelog](https://www.kimi.com/code/docs/en/kimi-code-cli/changelog.html)). `Agent` (prompt, subagent_type coder/explore/plan/custom, `resume`, `run_in_background`); fresh context, only the final result returns, built-ins cannot nest. `AgentSwarm` (`prompt_template` with `{{item}}` + `items`): up to 128 subagents, only while user enables `/swarm`, 5 start then +1 per 700 ms (cap via `KIMI_CODE_AGENT_SWARM_MAX_CONCURRENCY`), one aggregated report. Since 2.3.2 (2026-10-25) no proactive subagents; experimental Tower adds isolated worktrees plus review.

- **(c) DeepSeek**: official [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (MIT, developer preview). `subagent` (fresh) / `subagent_fork` (parent's completed turns) return immediately; defaults `maxActiveSubagents` 8, `maxDepth` 1; parent gets a completion notice with the final answer ([docs](https://deepseek-harness.github.io/deepseek-harness/en/reference/subsystems/subagent)). Workflow scripts (`agent()`/`parallel()`): concurrency min(16, cores-2), 1,000 total. [API docs](https://api-docs.deepseek.com/) list it beside Claude Code, Codex, OpenCode; [changelog](https://api-docs.deepseek.com/updates) 2026-10-17: V4.1-Flash optimized for DSH/CodeBuddy, Terminal-Bench 4.0 run in Claude Code; Claude Code setup pins `CLAUDE_CODE_SUBAGENT_MODEL=deepseek-flash`. - **(d) Qwen Code** ([subagents](https://qwenlm.github.io/qwen-code-docs/en/users/features/sub-agents/), [Agent tool](https://qwenlm.github.io/qwen-code-docs/en/developers/tools/task/)). `agent`: `subagent_type` (incl. `fork`), `run_in_background` (default true), `isolation: worktree`; several calls per message run in parallel. Regular subagents lack parent history, return the result inline or by notification; forks inherit history, share prompt cache, cannot spawn. Depth default 5; `maxSubAgents` exists ([weekly 2026-07-09](https://qwenlm.github.io/qwen-code-docs/en/blog/updates/weekly-update-2026-07-09/)), default not found. Experimental Agent Team (`/coordinate`, three workstreams, read-only workers, leader merges) and [Arena](https://qwenlm.github.io/qwen-code-docs/en/users/features/arena/) (5 agents, worktrees).
