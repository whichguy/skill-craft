- 1. Tools and enabling. V1: `spawn_agent` (message|items, agent_type, fork_context, model, reasoning_effort), `send_input`, `resume_agent`, `wait_agent` (targets[], timeout_ms), `close_agent` [verified: https://learn.chatgpt.com/docs/config-file/config-reference]. V2: `spawn_agent` (required task_name, message; optional agent_type, fork_turns, model, reasoning_effort), `send_message`, `followup_task`, `wait_agent` (timeout_ms only; returns who has mail, not content), `interrupt_agent`, `list_agents` [verified: https://github.com/openai/codex/blob/main/codex-rs/core/src/tools/handlers/multi_agents_spec.rs]. `agents.enabled=false` is the only effective off switch (unless `multi_agent_v2` is true): `features.multi_agent_v2` defaults false, yet the bundled catalog pins V2 for every listed model except gpt-5.6-luna (V1) and gpt-5.5 (unset), so the flag cannot force V1; `features.multi_agent` is deprecated [verified: https://github.com/openai/codex/blob/main/codex-rs/models-manager/models.json; #31097, #32705]. The parent blocks in `wait_agent` or ends its turn; results arrive by mailbox.

- 2. Limits. V1: `agents.max_concurrent_threads_per_session` (alias `max_threads`) defaults to 6 spawned threads, primary excluded; finished agents count until closed; `agents.max_depth` defaults to 1. V2: `features.multi_agent_v2.max_concurrent_threads_per_session` defaults to 4 and includes the root (3 concurrent subagent turns, best effort); `agents.max_depth` is V1-only, so V2 has no depth limit. `wait_agent` timeout: default 30 s, min 10 s, max 1 h. No per-agent runtime timeout; `job_max_runtime_seconds` is a removed no-op [verified: https://github.com/openai/codex/blob/main/codex-rs/core/src/config/mod.rs, #26969]. Responses API beta: `max_concurrent_subagents` 3, root extra [verified: https://developers.openai.com/api/docs/guides/responses-multi-agent].

- 3. Context. V1 omitted `fork_context` means fresh (prompt only). V2 `fork_turns` defaults to all (full history); none is fresh; numbers now also mean all. The parent gets summaries only. Model and effort resolve spawn argument, then `agents.default_subagent_*`, then parent. Sandbox, approvals and cwd are copied live from the parent turn; roles cannot override. V2 children share one directory, no worktrees [verified: source; https://learn.chatgpt.com/docs/agent-configuration/subagents].

- 4. Parallel tasks. App worktree mode: separate checkout in `$CODEX_HOME/worktrees`, detached HEAD, 15 kept by default, snapshot before deletion; Local mode shares the checkout [verified: https://learn.chatgpt.com/docs/environments/git-worktrees]. Cloud: each task has its own workspace; concurrency cap not found. Best of N: `codex cloud exec --env ID --attempts 1-4`, then `--attempt N` to diff or apply [verified: https://learn.chatgpt.com/docs/developer-commands?surface=cli, source]; per-attempt containers and a six-thread-per-environment cap are [secondary, unverified].

- 5. Cost and latency. Codex: more tokens than one agent, time saved only on independent work, parallel writes conflict; no speedup numbers found [verified: subagents doc]. Ultra with 8+ slots can raise usage quickly [verified: #31621]. Copilot: /fleet can consume more AI credits; cloud sandboxes meter $0.000024 per vCPU-second from November 2026 [verified: https://docs.github.com/en/copilot/concepts/agent-capabilities/choosing-and-delegating-agent-work/delegating-and-parallelizing-work-with-agents].

- 6. Copilot. Cloud agent: isolated sandbox or Actions runner, one branch and one PR per task, pushes only to a `copilot/` branch, human must review and merge, Actions sessions capped at 59 minutes; no concurrency number documented [verified: https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github]. Copilot app (GA 2026-06-17): each session gets its own git worktree and branch, or the current checkout, or a cloud sandbox [verified: https://docs.github.com/en/copilot/how-tos/github-copilot-app/agent-sessions]. Agent HQ assigns issues to Copilot, Claude or Codex, each producing a PR (public preview); Agent Merge fixes CI failures and conflicts but does not replace review. CLI /fleet subagents get their own context; concurrency by plan: Free 2, Pro 4, Max 8, Business 16, Enterprise 32; depth default 6 in one table, 4 in another [verified: https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-command-reference].
