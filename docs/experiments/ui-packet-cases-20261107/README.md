## Decisions retained

1. **Judge the packet's duties, not an author's preferred answer format.** Admit inline named labels, numeric viewport sizes, shared test setup, unchanged tests and declared scratch proofs. Keep criterion-level selection and functional obligations explicit. Decouple record and criterion checks so one parser failure does not manufacture two independent findings.
2. **Separate consistency from execution truth.** Implement/document P2 now checks contradictory current dispositions. Pasted PASS lines receive no special authority. Actual verification truth is withheld from automatic scoring and assessed using native receipts or host execution events. Do not add a broad run-directory export merely to score this cohort.
3. **Preserve design decisions in architecture.** Operational verification belongs in run records and environment documentation. Remove pending implementation state from the document seed's AD and retain a negative example for operational rendered-pass history there. This changes the test fixture, not ShipLoop's production policy.
4. **Distinguish script settlement from model continuation.** The test-spec callback accepted test-spec and validate-existing together in one traced command. Keep the original boundary negative, classify it as script co-settlement, and repair the harness while continuing to reject separate later actions.
5. **Treat repaired grading as evaluator debugging.** Preserve the original 25 positives and 57 negatives for comparison, author additional equivalent forms and contrary controls, and retain any changed reference verdict by name. Regrade only copied outputs under a separately identified evaluator. Never subtract old and new scores to claim subject improvement.

The named-subsection, anchor-sufficiency and light-default interpretations remain qualified. This round changes no production prompt, UI default, model selection or loop policy, and infers no new owner decision from ambiguous wording.

The owner's mobile/web clarification adds a [prospective layout matrix](../../../test/shiploop_e2e/stage_cases/MOBILE-WEB.md). These additional cases were not registered or executed in the original ten-sample cohort; no new coverage is inferred from the existing narrow-browser observations.
