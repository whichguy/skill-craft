2. Mechanism
- The home router's reverse-DNS answer for the Mac's address lists three names, the first a dotless <identifier>
  (`dscacheutil -q host -a ip_address`: name: <identifier>); IPMonitor took it as the hostname.
- git 2.54.0 (Apple Git-157), with no configured email, guesses user@hostname. The hostname has no dot and
  getaddrinfo(hostname, AI_CANONNAME) fails (EAI_NONAME), so git appends ".(none)" and refuses to commit:
  "fatal: unable to auto-detect email address (got 'user@<identifier>.(none)')"   [git var GIT_COMMITTER_IDENT, empty home]
