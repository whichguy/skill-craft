Write slug.py, a small command-line tool: `python3 slug.py TITLE` prints TITLE as a URL slug on standard output and exits 0. Lowercase the letters, turn each run of spaces or punctuation into a single hyphen, and drop hyphens from both ends, so "Hello, World!" gives hello-world and "  Many   spaces here " gives many-spaces-here. I also want an option `--max-length N` that cuts the slug to at most N characters without leaving a hyphen at the end, so `python3 slug.py "Hello, World" --max-length 8` gives hello-wo and `--max-length 6` gives hello. Build only the basic tool in this run and leave `--max-length` for a later run, because I want to see the basic tool first; until then the tool should treat any option it does not know as an error and exit with status 2. Add unit tests with unittest.
