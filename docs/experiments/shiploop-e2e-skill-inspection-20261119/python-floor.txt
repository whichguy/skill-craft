## The two runtime needs, called directly
listeners.unreaped is the builder wait loop's check: run.py calls it as 'while listeners.unreaped(proc.pid) == "running"'.
It uses os.waitid, which macOS Python gained in 3.13. zip(strict=True) is used by the bundled game oracles (oracle_games.py, verify_tictactoe.py).

| Python | listeners.unreaped (os.waitid) | zip(..., strict=True) |
|---|---|---|
| 3.9.6 | AttributeError: module 'os' has no attribute 'waitid' | TypeError: zip() takes no keyword arguments |
| 3.11.15 | AttributeError: module 'os' has no attribute 'waitid'. Did you mean: 'waitpid'? | works |
| 3.13.17 | works: running | works |
| 3.15.1 | works: running | works |

So on macOS a real run of the source harness needs Python 3.13 or newer; on Linux os.waitid exists in every 3.x.
The hermetic suites cannot show this: test/shiploop-e2e-hosts.test.py skips its process-group tests when os.waitid is missing
(@unittest.skipUnless(os.name == "posix" and hasattr(os, "waitid"), ...)), so they pass on 3.11 while a real run fails.
(test/run_suites.py has its own ctypes waitid for Darwin; listeners.py does not.)
The bundled game oracles need 3.10. Nothing found needs 3.15, which the skill's documents state.
