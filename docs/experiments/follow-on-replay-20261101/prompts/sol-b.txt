You are one of several independent readers. Your job is to classify short texts. Do not run commands, open files or use any tool: judge only what is written below.

CONTEXT
A coding harness called ShipLoop builds software for a written request, tests it and delivers it. At the end of a run it writes a short text under the heading "Open for the next run": what a later run should pick up. Each ROW below is one such text, with the request that run was given (as numbered sentences). Rows are unrelated; judge each on its own.

CLASSES (choose exactly one per row)
- gap: a request outcome or a refuted assumption that the system could close without a person
- note: knowledge for a later change (a recorded default, where to resume); nothing is open
- debt: a small hygiene item inside the request's scope (a test to keep, a documentation line)
- extension: optional or conditional scope beyond what the request asks
- capability: a later run with a capability this run lacked (a headed browser, a Lightning UI, a Windows host) could close it
- person: a person must do or confirm something (a manual check, a click-through)
- decision: names a choice or an answer a person must give about the spec or scope before anything is built

FOR EACH ROW give
  "class": one of the seven class names above, exactly as written;
  "alt": another class that is also a reasonable reading of the same text, or null if you see none;
  "reason": one sentence of at most 25 words.

OUTPUT
Reply with one JSON array and nothing else, one object per row, in the order given, using the ids exactly as written:
[{"id": "r01", "class": "...", "alt": null, "reason": "..."}, ...]
