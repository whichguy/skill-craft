#### Key learning

- A dedupe invariant needs a walk with a baseline: the unit tests of the packets branch had no case in which the spec was new and not quoted, so the biggest remaining repeat (about a quarter of a document or verify block) had no test. `WalkedBlockTests` builds it from the same two-item multi-step run the head tests use.
- Where a line says "above" or "below", the builder must know the order: `_diff_printed_files` takes only the sources after the entries.
- The anchor form of the delivery block is also the cheapest S-6 check available offline: a stage without the contract still names the record, the obligation IDs with their phase and the standing exclusions, and a replanning or recovery notice still prints at every stage (test).
