## Key learning

- A line that quotes a marker defeats every reader that searches for the marker: line B (plan 6.2's own text) put the end line in the first 600
  characters of every print, which survives any cut, so "the print has its end line" stopped meaning "the print is whole" for three harness readers
  until they matched a line. The plan's red team did not see it: it checked the packet, not the readers of the packet.
- Eleven readers (nine of them copies of one helper) parsed the pointer as "the rest of the line", and so did the E2E counters. The shared helper now
  owns the parse in the suites, so the next change to that line edits one function.
- A within-packet duplicate hides in the lookup tier: the stub, the footer and line B said the same things, and the plan's list of what goes named them
  by sentence, not by symbol. The deletion needed the symbol (`QUOTED_STUB`) found by `git grep`.
