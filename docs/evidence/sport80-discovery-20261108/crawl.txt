Sport80 (usaweightlifting.sport80.com) menu-graph crawl, 2026-11-08
Method: GET only, from a tab signed in as the owner, one request at a time (~120 ms apart), following the server's own
menu definitions (/api/menu/main and /api/menu/top for each role) and then every tab-menu, redirect and list URL they
return, to depth 3. 74 requests, 81 result lines. Structure only: field and filter names, counts, HTTP status. No row
values, no ids, no tokens. Role ids are shown as <cid> (personal) and <body_cid> (club). "?a,b" lists query parameter
NAMES only. "*" after a column marks it sortable.

Kinds:  TABLE = descriptor of an s80-datatable (rows come from its data_url by POST)
        TABS = s80-tab-menu (each tab is another endpoint)
        REDIRECT = {type,url} pointer to the real list
        INERTIA = server-rendered page with a data-page JSON payload (component name + prop names)
        HTML = legacy server-rendered fragment (structure read from the DOM)
        JSON = plain JSON object (key names)
