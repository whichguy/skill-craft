## Verification boundaries

Runtime-composition fixtures execute real local CLIs but their synthetic review
judgments do not prove semantic Improve quality. Copied-package invocation is
distinct from marketplace installation or live host execution. No hosted
deployment is needed to repair the demonstrated local failures. A live
latency comparison or source-branch-triggered deployment redesign requires its
own fixed-input experiment; preserve final return ordering in this change.

## Results

The implementation preserves all 34 producer stages. Each producer still parks
its parent action while the selected standalone Improve skill runs its own Until
Loop. Stage-specific references and compact decision locators now reach both
the producer and that child handoff.

Delivery projection now accepts negative observations at product acceptance,
release checks, and operations when the relevant observation is due. An accepted
v3 outer replan invalidates the previous release plan even when the corrective
work changes the contract later. A material post-plan correction still needs
fresh system tests and release planning; repeat/resume does not clear it.

Large requests, work-item context, evidence lists, pending Improve results, and
status/delivery context use bounded inline excerpts with explicit full-record
locators. Saved values remain complete. Oversized result templates become a
valid minimal JSON example with an instruction to read and supply the full
required assessment, rather than malformed truncated JSON.

These measurements describe the isolated task candidate; concurrent guidance
