## What each part measures, and the evidence

Everything below was recomputed from `/Users/dadleet/e2e-runs` (22 run folders with a `result.json`, 3 more with a launch
record only) and the 23 committed rows. Where the design text disagreed, the recomputation wins.

**Plugin tree digest (`plugin_sha256`).** sha256 over each file's relative path and the sha256 of its bytes, in sorted path
order, leaving out `__pycache__`, `*.pyc`, symlinks and non-files; 12 hex. v1220-battleship-sonnet 19868f9ee770 against
v1230-battleship-sonnet 452b7e2eb831 (both plugin 1.22.0 / ShipLoop 0.54.0); r1-battleship-sonnet, r1-checkers-sonnet and
r1-battleship-grok-none all 3a7515d2efd3. The design's values (142047ca62ed for the r1 trio) came from a different
algorithm and are not reproduced; the equivalence classes are the same. Pinned by a golden value on a two-file tree
(`96788439bf74`) so a saved report stays reproducible.

**Prompt digest (`prompt_sha256`).** sha256 of the prompt with `str(out)` replaced by `<output>`, stripped, 12 hex.
The five Grok `none` prompts: five raw 8-hex hashes (f32a5a16, 0a4c7bbe, 4a7bc018, f45d5e6e, cd6dbebe), one masked
(5ea67bf3...). Named cases: battleship d0c0cbe71344, checkers e4da54c7f03d.

**Host build (`host_build`).** Claude: `metrics.claude_code_version` (init event); for an older run whose metrics lack it,
the report reads the init event in `events.jsonl` (v1220: 2.1.291). Grok and Codex: first stdout line of `<cli> --version`
(`grok 1.0.50 (c58f321264ba)`, `codex-cli 0.162.0`), probed once per launch in `_main` and written on that launch's record;
a regrade restates the recorded value; the report reads launch records only. Null for every Grok or Codex run launched
before this change, by design (audit correction 3).

**Span, planning window, head.** `started`/`ended` are the first and last stamp of `timeline.jsonl`
(`metrics.span`); `planning_seconds` is `metrics.planning_seconds(planning)`, the closed window on the engine's clock and
null while open or unreadable; `local_head` is `versions.local_head` (checkout) or `versions.released.local_head`
(marketplace). **Which source wins** (audit correction 13): when a row and a folder both describe a run, the row wins
wherever it has a value, the folder fills the rest, and the derived identity fields are listed in `recomputed`.
v1230-battleship-sonnet's file row has no planning figure; its regraded `metrics.json` holds a closed 388 s window, so the
Battleship planning cell is n = 4 of 5 (4.85 / 5.56 / 6.47 minutes), not the design's 3 of 5.

**One matching rule.** `run.matching_rows(...) -> (rows, seen, skipped)`; `scan_baseline` and `previous_row` are wrappers
(a test fails if either grows its own `json.loads`). Usable = same case and source, same host/model/effort, same
`planning_review` mode (unchanged), prompt key, and `row_reached_done`. `row_reached_done` is false when
`verdicts.shiploop` is false or `termination.engine_status` is anything but done; a row with neither field is kept.
Prompt key: always for case `custom` (a hash on both sides and equal), only when both carry one for a named case.
Transitional break (named in SPEC, README and the commit): the two committed Grok `none` rows (17 and 19) match no new
`custom` run until a row with the hash exists; the 23 committed rows keep comparing for named cases.

**Subject run.** A run whose own engine did not reach done still writes its row and prints
`baseline  nothing compared: this run did not reach done (engine blocked)`. This is the r1 Grok defect
(`turns 503 -> 301, cost $14.1673 -> $8.7455` in `r1-grok.log`, against the blocked 2026-10-07 row).

**The report.** Over the real data: 35 attempts in 15 cells (13 in the file and a folder, 12 in a folder only, 10 in the
file only): 15 counted, 9 rows that name no host/model/effort, 4 not done, 3 resumed, 3 with no result, 1 mixed host.
Sonnet Battleship: n = 5 on 5 plugin trees and host builds 2.1.291/2.1.292/2.1.294, cost 5.6749 / 5.8146 / 9.6543, turns
197 / 207 / 294, minutes 12.6 / 13.8 / 20.0, overlap at least 4 of 5 (v1220 ran alone). Sonnet Checkers: n = 3, cost
5.1613 / 6.6509 / 8.5146, turns 185 / 232 / 293, planning 5.67 / 6.12 / 7.02. Grok `none`: 5 attempts, 1 counted
(v1220: 467 turns, $12.5014, lower bound), 2 not done (v1230, r1), 1 mixed host (r2), 1 resumed (r3). The loop's rows in
the committed file: r1 Checkers, r3 Battleship, r3 Checkers (3 of 7); r1 Battleship, r1 Grok, r2 Battleship and r2 Checkers
exist only as folders. A cell has no two runs of one build, so build effects and run-to-run spread cannot be separated; the
report says so and makes no within/above/below claim.

**Grok session count.** See the commit `073fd4dd` message and the LEARNINGS entry. `available_commands` is repeated inside
one session (r1: 314 for 2 `end`, 301 model calls); `end` is the only per-session marker. The count is null with a reason
and the marking stays. **The rule G2's sessions.jsonl will enable:** a launch's first line is known to `run.launch` (`line`
at its start), so a launch whose line range holds no `end` event never reported; counting those gives an exact
`unreported_sessions` and replaces the null.

## Audit corrections: where each went

1. Regrade is not a resume: implemented (`classify_attempt`; `RecordedLoopRunsTest`, `BaselineReportClassTest`).
2. Mixed-host detection: implemented through `runrecord.mixed_host`; r2-battleship-grok-none is `mixed host`.
3. No `Host.cli_version` for past runs: implemented; tests patch the probe to raise.
4. `MIN_EARLIER_ROWS`/within-above-below: removed; the SPEC states the 2/(n+1) fact (at most, without ties) and no claim.
5. Subject run must be done: implemented.
6. Name the transitional break: SPEC, README, commit message; smaller key chosen and pinned.
7. Grok lower bound: marking kept and carried into the report (`lower_bound`, `lower_bound_rows`); the start count is
   null (see above).
8. result.json `spread` block and the `_main` reorder: deferred. `host_build` and `versions.plugin_sha256` are restated by
   a regrade (the part of this correction that remains).
9. `--repeat` deferred, `harness_sha256` dropped, `local_head` copied from both places: done.
10. No second implementation of the rebuild: `runs.json` is the shipped command's output.
   `docs/experiments/baseline-spread-20261009/reduce_fixtures.py` only reduces folders to fixtures; it computes no row.
11. README phrases `no overlap field` and `a discipline and not a guarantee`, and the SPEC bullet heading and exception
   sentence: kept (LeftBehindReadmeTest passes unchanged).
12. Overlap wording: `at least k of n ... overlapped another recorded run`, `unknown` for a row with no span, and
   `not_seen_overlapping` beside the wall-time figures (the audit's n_clean; named so that it is not read as "clean").
13. Planning minutes source: stated above.
14. Minor figures: not relied on.
15. Hand-off: below.

Disagreements: none. Deviations from the design text, and why:
- The `sample:` facts are a line under `baseline vs` and not appended to it (that line is already ~200 characters). No live
  spread line is printed: the report prints min/median/max, and the brief made the live line optional.
- `matching_rows` returns a third value (why each other row was skipped) so the 'nothing compared' line can name the reason.
- `--baseline-report` lives in `run.py` beside `scan_baseline`, not in a new module: one code path (S-12), and a new
  module importing `run` would import it twice when run as a program.
- A cell's `source` is the first launch's (`invocation.json`), normalised to the part before ' (': r3-battleship-grok-none
  was started as a checkout run and resumed on a marketplace install; it belongs with its first launch.
- A `plugin_dir` outside the run's own folder is never digested after the fact (the same reasoning as the host build).
- FAKE_GROK/FAKE_CODEX in `test/shiploop-e2e.test.py` get no `--version` branch: the new tests wrap the shared fakes. One
  existing test there is edited (`MetricsTest.test_a_session_killed_before_it_reported_makes_the_cost_a_lower_bound`:
  its bare `available_commands` is now the Codex shape).

## Data shapes for the Run Review session (exact keys)

**Baseline row** (`baselines.jsonl`, new keys, null where unknown): `plugin_sha256` ("3a7515d2efd3"), `prompt_sha256`
("d0c0cbe71344"), `host_build` ("2.1.294"; Grok "grok 1.0.50 (c58f321264ba)"; null for old Grok/Codex), `local_head`
(40 hex), `started`, `ended` (epoch seconds, 1791481009.116 / 1791481838.24), `planning_seconds` (336.0). Not a row key,
by test: `unreported_sessions`.

**result.json**: top-level `prompt_sha256`, `host_build`, `span: {started, ended}`; `versions.plugin_sha256`;
`metrics.planning_seconds`. **metrics.json**: `span: {started, ended}`; `unreported_sessions` is null for a stream with
Grok events and `unmeasured.unreported_sessions` carries the reason. **Launch records** (`invocation.json`,
`invocation-resume-<host>-<seconds>.json`): `host_build` (null for Claude), `versions.plugin_sha256`.

**`run.py --baseline-report --json`** is `{inputs, records, cells, notes}`.
`records[]`: `output`, `record` ("file" | "folder" | "file+folder"), `case`, `source`, `host`, `model`, `effort`,
`planning_review`, `prompt_sha256`, `plugin_version`, `plugin_sha256`, `host_build`, `local_head`, `started`, `ended`,
`minutes`, `planning_seconds`, `planning_minutes`, `cost_usd`, `turns`, **`lower_bound`** (the lower-bound marker: true,
false, or null where the run's metrics are not there), `pass`, `engine_status`, `process_status`, **`hosts_used`** (the
mixed-host evidence, e.g. ["grok", "claude"]), **`class`** (the mixed-host flag is `class == "mixed host"`; the others:
"counted", "did not reach done", "resumed", "seeded", "process not observed", "no driver recorded", "no result.json"),
`why`, `recomputed` (identity fields the report derived), `overlaps` (null with no span).
`cells[]`: `cell` {`case`, `source`, `host`, `model`, `effort`, `planning_review`, `prompt_sha256`}, `attempts` {`seen`,
`counted`, `passed`, `did_not_reach_done`, `mixed_host`, `resumed`, `seeded`, `process_not_observed`,
`no_driver_recorded`, `no_result`}, `builds` {`plugin_sha256`: {digest: rows}, `unrecorded`}, `host_builds` {build: rows,
`unrecorded`}, `measures` {`cost_usd`, `turns`, `minutes`, `planning_minutes`: each `n`, `min`, `median`, `max`,
`not_measured`; `cost_usd` and `turns` also `lower_bound_rows`, `lower_bound_unknown_rows`}, `overlap` {`rows`,
`overlapped_at_least`, `not_seen_overlapping`, `unknown`}, `outputs` {class: [run names]}.
Example record and cell: r1-battleship-sonnet and the Sonnet Battleship cell in `docs/experiments/baseline-spread-20261009/runs.json`
(the committed output of `run.py --baseline-report --baseline test/shiploop_e2e/baselines.jsonl --runs /Users/dadleet/e2e-runs --json`).
